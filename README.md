# Ozon Claims Tracker — трекер клеймов на новых карточках (корма/лакомства, собаки+кошки)

## Как это работает

Полностью автономный ежедневный запуск на Ozon ненадёжен: сайт активно защищается от
ботов на глубоких URL, а фильтр «Новинки» отражает не все реальные новые карточки, а то,
что Ozon продвигает алгоритмически. Поэтому процесс — полуавтоматический: вы просите
Claude сделать очередной запуск (в чате или по расписанию), Claude сам ходит в браузере
по Ozon и обновляет файлы, вы получаете обновлённый Excel.

Важно: «новая карточка» — это карточка товара на Ozon, которую мы раньше не видели, а
не обязательно товар, впервые вышедший на рынок. См. «Ограничения метода» ниже.

## Категории (7 подкатегорий)

- Собаки: `suhie-korma-dlya-sobak-12303`, `vlazhnye-korma-dlya-sobak-12304`,
  `lakomstva-dlya-sobak-12305`, `kashi-dlya-sobak-30158`
- Кошки: `suhie-korma-dlya-koshek-12349`, `vlazhnye-korma-dlya-koshek-12350`,
  `lakomstva-dlya-koshek-12351`

URL вида `https://www.ozon.ru/category/<slug>/` (обычная сортировка) и
`https://www.ozon.ru/category/<slug>/?sorting=new` (кандидаты в новинки).

## Методология определения «реальных» новых карточек

1. Фильтр Ozon «Новинки» — быстрый, но неполный источник кандидатов.
2. Надёжный способ — сравнение ID товара с `data/products_history.csv`: если ID
   раньше не встречался ни в одном срезе — это подтверждённая новая карточка.
3. Дополнительный сигнал: у более новых карточек, как правило, больше числовое
   значение ID (создан позже в системе Ozon) — полезно для быстрой сортировки
   кандидатов, но не заменяет полноценное сравнение с историей.
4. День 0 (2026-07-31) — только формирование базовой истории; полноценные
   недельные тренды по-настоящему новых карточек появятся после нескольких
   ежедневных срезов.

## Ограничения метода

1. **Ложные срабатывания.** «Объективно новый ID» доказывает лишь то, что карточка
   на Ozon появилась в поле зрения впервые — не то, что сам товар впервые вышел на
   рынок. Из-за высокой доли 3P-продаж на Ozon один и тот же товар может получить
   новую карточку с новым ID при листинге ещё одним продавцом или при повторном
   листинге тем же продавцом. Распознанные вручную дубли (по фото/описанию) не
   учитываются повторно в аналитике, но метод не гарантирует, что все подобные
   случаи пойманы.
2. **Пропуски.** Порог «ID выше максимума» предполагает монотонный рост ID во
   времени внутри подкатегории. Если это нарушится (новая карточка получит ID
   ниже уже зафиксированного максимума), метод её не заметит вовсе. Подтверждено
   на практике 2026-08-12: в выдаче `?sorting=new` категории «Влажные корма для
   кошек» найдены карточки без отзывов с бейджем «Новинка» и ID ниже нашего
   порога (см. `data/id_audit/`). Как частичная компенсация — при каждом запуске
   дополнительно фиксируется ID-диапазон из `?sorting=new` по каждой подкатегории;
   карточки ниже порога заносятся в `data/id_audit/` для ручной проверки, но не
   считаются подтверждёнными.

## Файлы

- `data/products_history.csv` — все ID товаров, когда-либо встреченные, с датой
  первого обнаружения. Пополняется при каждом запуске.
- `data/claims_log.csv` — список товаров, для которых уже проанализированы клеймы
  с упаковки (чтобы не разбирать повторно).
- `photos/<дата>/` — сохранённые фото упаковок проанализированных товаров.
- `reports/claims_report.xlsx` — итоговый файл для вас:
  - **Примеры** — карточки товаров с клеймами (кратко) и ссылками на Ozon/фото.
  - **Клеймы** — детализация: 1 строка = 1 товар × 1 категория клейма, с точной
    формулировкой с упаковки.
  - **Клеймы-справочник** — таксономия из 11 категорий клеймов с описаниями.
  - **Аналитика** — подсчёт (формулами COUNTIF) числа новых карточек в каждой категории,
    диаграмма и текстовые выводы.

## Как попросить обновление

В чате с Claude: «сделай очередной запуск трекера клеймов» — Claude:
1. Обойдёт 7 категорий (обычная сортировка + `?sorting=new`), сравнит ID с
   `products_history.csv`, выделит подтверждённые новые карточки.
2. Для новых ID откроет карточку, посмотрит фото упаковки, определит клеймы по
   таксономии из `Клеймы-справочник`.
3. Допишет строки в `Примеры` и `Клеймы`, обновит счётчики в `Аналитике`.
4. Раз в 7 дней — попросите «сделай недельную аналитику» — сформируется отдельный
   срез с трендом (растущие/падающие направления клеймов) по сравнению с
   предыдущей неделей.

Также можно настроить автоматическое напоминание через `/schedule` (например,
каждый будний день утром прислать вопрос «пора обновить трекер клеймов?»).
