    Методология

    Новинки определяются не по фильтру Ozon «Новинки» (он алгоритмический и продвигает не только объективно новые товары — это подтвердилось на второй день наблюдений, когда состав «Новинок» почти полностью обновился, включая товары со старыми ID). Вместо этого ведётся база ID всех встреченных товаров по 7 подкатегориям (сухие/влажные корма, лакомства, каши — собаки и кошки). Товар считается объективно новым, если его ID выше максимального ID, ранее зафиксированного в этой же подкатегории — то есть он физически не мог существовать на момент предыдущего снимка.

    Клеймы считываются вручную с фотографий упаковки (не автоматическим OCR), чтобы верно интерпретировать маркетинговый смысл формулировок.

    Протеин и ингредиенты-клеймы в карточках товаров — это только то, что вынесено крупно на лицевую сторону упаковки (например, «ягнёнок», «омега-3», «облепиха»), а не полный состав мелким шрифтом на обороте. Завод-изготовитель — юрлицо и адрес производства с этикетки (не бренд и не импортёр/официальный представитель) — указывается там, где его удалось разобрать по доступным фото в галерее Ozon; для части товаров подходящего фото просто нет.

    Данные собраны вручную с публичных карточек товаров Ozon в исследовательских целях. Не является рекламой и не аффилировано с Ozon.
